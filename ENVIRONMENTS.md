# Перемикання Local / Live

Усі API-запити проходять через `src/config.js`. Не потрібно змінювати адреси вручну в компонентах.

## Локальна розробка

```bash
npm run dev:local
```

Використовується поточний домен Laragon (`nexaflow.test`) і локальний `/api`.

## Перевірка live-збірки

```bash
npm run dev:live
```

Цей режим звертається до `https://nexaflow.top/api`.

## Збірка для публікації

```bash
npm run build:live
```

Після збірки вміст `dist` можна завантажувати на live-сайт. Для повсякденної роботи залишайтеся в `local` режимі.
