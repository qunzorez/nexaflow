# Середовища NexaFlow

Єдиний перемикач: `appsettings.json`, поле `environment`.

- `develop` (за замовчуванням у Git): локальна база з `api/config.local.php`, пошта в Mailpit на `127.0.0.1:1025`, Telegram вимкнений. Листи переглядайте на http://localhost:8025. Дані живої бази автоматично не підставляються.
- `web`: жива база, PHP mail() хостингу, Telegram увімкнений. Сервер читає секрети з `api/config.web.php`, або зі старого серверного `api/config.local.php`, або `api/config.php` для сумісності.

У `profiles` можна змінити адресу сайту, транспорт пошти і дозвіл Telegram. Паролі й токени не додавайте до JSON. Для окремого локального тестового бота можна ввімкнути `telegram_enabled` у develop і вказати його токен у локальному PHP-конфігу.

## Публікація

1. Виконайте `npm run build` і запуште зміни разом із `dist`.
2. У cPanel Git виконайте Update from Remote, потім Deploy HEAD Commit.
3. `.cpanel.yml` копіює JSON у `public_html` та запускає `tools/set-web-environment.php`, який встановлює `web` **лише в опублікованій копії**. Локальний JSON залишається `develop`.

Сам merge/push не оновлює сайт, якщо автоматичне виконання cPanel deployment не налаштоване. При ручному завантаженні файлів обов’язково встановіть `environment: web` у серверному JSON.

Серверні `config.local.php` і `config.web.php` не перезаписуються деплоєм. Рекомендовано один раз скопіювати наявний серверний конфіг у `api/config.web.php`: усі ключі бази, пошти й Telegram зберігаються. Ці файли ігноруються Git.

React звертається до `/api` того самого сайту: готова збірка не містить адреси чужої бази чи API. При `npm run dev` проксі використовує адресу профілю з JSON. Після зміни JSON перезапустіть Vite; PHP та cron читають режим при наступному запуску.

Початковий локальний конфіг (якщо його немає):

```php
<?php
return [
    'host' => '127.0.0.1', 'port' => 3306,
    'database' => 'srm_local', 'username' => 'root',
    'password' => '', 'charset' => 'utf8mb4',
];
```

Вибір середовища не копіює і не очищає базу даних. Налаштування отримання email конкретного користувача продовжують застосовуватися незалежно від середовища.
