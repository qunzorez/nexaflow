# Налаштування Telegram-бота NexaFlow

## 1. Створення або налаштування бота

1. Відкрийте Telegram і знайдіть `@BotFather`.
2. Надішліть `/mybots`.
3. Виберіть бота `@nexaflows_bot`.
4. Відкрийте **Bot Settings → Edit Description** і додайте опис, наприклад:

   `NexaFlow надсилає сповіщення про задачі, проєкти та перевірки.`

5. У **Edit Commands** додайте:

   ```text
   start - Підключити NexaFlow
   help - Допомога
   ```

## 2. Безпека токена

Токен бота не можна додавати у Git, frontend або надсилати іншим людям.
Оскільки попередній токен був показаний на скріншоті, його потрібно відкликати через **BotFather → Revoke token** і створити новий.

Локально токен зберігається тільки у файлі:

```text
api/config.local.php
```

У конфігурації має бути:

```php
'telegram_bot_token' => 'НОВИЙ_ТОКЕН_ВІД_BOTFATHER',
```

Файл `api/config.local.php` ігнорується Git.

На живому сайті цей параметр потрібно додати у серверний `api/config.local.php` через cPanel File Manager. Не вставляйте токен у `config.php`, який публікується через Git.

## 3. Підключення користувача

Кожен користувач повинен один раз:

1. Відкрити `@nexaflows_bot`.
2. Натиснути **Start** або надіслати `/start`.
3. Отримати свій `chat ID` через `@userinfobot` командою `/start`.
4. Відкрити NexaFlow → **Налаштування профілю**.
5. Заповнити:
   - **Telegram-тег** — наприклад `@andrey`;
   - **Telegram chat ID** — числовий ID із `@userinfobot`.
6. Натиснути **Зберегти зміни**.

Telegram-тег використовується як контактне ім’я. Відправка повідомлень виконується через `chat ID`, тому одного тега недостатньо.

## 4. Які повідомлення надсилаються

Після підключення користувач отримує Telegram-повідомлення про:

- призначення задачі;
- необхідність перевірити задачу;
- підтвердження виконання задачі менеджером;
- повернення задачі на доопрацювання.

Повідомлення також зберігаються у внутрішньому розділі **Сповіщення** NexaFlow.

## 5. Перевірка

1. Переконайтеся, що користувач натиснув `/start` у боті.
2. Перевірте правильність `chat ID` у профілі.
3. Створіть тестову задачу та призначте її цьому користувачу.
4. Перевірте Telegram і внутрішні сповіщення NexaFlow.

Якщо Telegram не надсилає повідомлення, перевірте, що PHP на хостингу має увімкнений модуль cURL і що новий токен доданий саме у серверний `api/config.local.php`.
