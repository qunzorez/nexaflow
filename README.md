# SRM Hub — фундамент web-додатка

## Як відкрити

Відкрийте файл `dist/index.html` у браузері. Зараз це статичний прототип без встановлення залежностей.

## Що вже є

- адаптивна сторінка входу та реєстрації;
- базовий дизайн SRM Hub;
- перемикання між входом і реєстрацією;
- PHP API для реєстрації та входу через MySQL;
- хешування паролів через `password_hash`/`password_verify`;
- валідація пошти, пароля та умов використання.

## Важливо про базу даних

Для локального запуску backend потрібен PHP із PDO MySQL. На HOSTiQ створено базу `nexaflow_srm` та користувача `nexaflow_srmuser`. Перед запуском API замініть `CHANGE_ME_DB_PASSWORD` у `api/config.php` на пароль користувача БД. Пароль не зберігайте в Git або публічних файлах.

## План наступних модулів

1. Реальний backend і база користувачів.
2. Dashboard після входу.
3. Клієнти та контактні особи.
4. Проєкти, етапи й задачі.
5. Ролі користувачів і права доступу.
